# Hearth Pi App

Independent, experimental Home Assistant App source for aarch64 and amd64. No published image or repository URL is available. The manifest starts with zero authorized users/entities and service actions disabled; it is not ready for use without explicit setup. See [installation/options](DOCS.md), [security](../docs/security.md), [validation](../docs/validation.md) and the [project overview](../README.md).

`hearth_pi/` is the self-contained Docker build context. App data resides in `/data`. Do not commit its contents or copy real HA credentials into issues.
